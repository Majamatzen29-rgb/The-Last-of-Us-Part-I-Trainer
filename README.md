## 1. Requirements

Before using the trainer, make sure you have:

- A PC running Windows.
- The PC version of The Last of Us Part I.
- A working keyboard with a numeric keypad for the Num shortcuts.
- The trainer downloaded from the official Nordic Mod Developer release.
- Enough free memory and storage to run your game normally.

**Important:** This is a Windows PC trainer. It is not an iPad app and cannot run directly on an iPad.

## 2. Downloading the Trainer

1. Open the Nordic Mod Developer GitHub repository.
2. Find the latest release of The Last of Us Part I Trainer.
3. Download the trainer `.exe` file from the release assets.
4. Save the file somewhere easy to find, such as your Downloads folder.
5. Wait for the download to finish before opening the file.

Only download the trainer from a source you trust.

## 3. Preparing Your Game

1. Start The Last of Us Part I on your PC.
2. Load your saved game or begin a new game.
3. Wait until you can control your character.
4. Keep the game running while you start the trainer.

If the trainer does not detect the game, close the trainer and game, then try starting the game first and the trainer second.

## 4. Starting the Trainer

1. Find the downloaded trainer `.exe` file.
2. Double-click it to open it.
3. If Windows displays a security warning, stop and verify that the file came from the official release before deciding whether to continue.
4. Keep the trainer open while playing.
5. Return to the game and press the shortcut for the feature you want.

The shortcuts below are the configured controls supplied for this trainer. Individual features may behave differently depending on the trainer build and game version.

## 6. Understanding the Features

### God Mode and Infinite Health
These options are intended to help you survive encounters and reduce the risk of being defeated.

### Infinite Ammo and No Reload
These options are intended to reduce ammunition limitations and the need to reload.

### Flamethrower No Reload
Designed to prevent the flamethrower from needing its usual reload behaviour.

### Super Accuracy and No Recoil
Designed to make aiming and shooting easier.

### Rapid Fire
Designed to increase the speed at which supported weapons fire.

### Infinite Shivs and Weapon Durability
Designed to help maintain shivs and supported weapon durability.

### Super Damage and Multipliers
Super Damage is intended to defeat enemies with much less effort. Damage and Defense Multipliers adjust the damage behaviour supported by the trainer.

### Stamina and Supplies
These options are intended to provide more stamina, health kits, throwable items, and crafting resources.

### Game Speed
This option is intended to adjust the game's speed. Use caution, because extreme speed settings may make gameplay unstable.

### Resource Editing
The Alt shortcuts are intended to edit the listed upgrade points and crafting materials.

**Note:** These descriptions explain the intended functions. Exact behaviour can vary by trainer version, and some features may require testing in-game.

## 7. Troubleshooting

### The trainer will not open
- Confirm that the download completed.
- Check that your Windows version is supported.
- Verify the file's source before running it.
- If Windows or your security software blocks the file, review the warning rather than blindly bypassing it.

### The hotkeys do not work
- Make sure the game is running.
- Start the trainer after the game has loaded.
- Click the game window before trying the shortcut.
- Check Num Lock.
- Use the numeric keypad rather than the number row above the letters.

### Some cheats work, but others do not
- Confirm that you downloaded the correct trainer for The Last of Us Part I.
- Check whether the game or trainer has been updated.
- Some features may only work in certain gameplay situations.

### The game crashes or behaves strangely
- Close the game and trainer.
- Restart the game without the trainer to see whether the problem remains.
- Restore your previous game settings if needed.
- Keep a backup of your save files.

## 8. Safety and Save Files
